# Terminal Music Player

A Node.js terminal-based music player built using JavaScript.

## Features

- 🎵 Play songs
- ⏸️ Pause
- ▶️ Resume
- ⏹️ Stop
- ⬆️⬇️ Select songs
- ❌ Quit
- 🎨 Colored terminal UI using Chalk

## Technologies

- JavaScript
- Node.js
- Chalk
- macOS `afplay`

## How to Run

```bash
npm install
node index.js
